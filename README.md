# MatrixNegativeColumns

## Назначение
Программа для поиска номеров столбцов вещественной матрицы n × m,
все элементы которых строго отрицательны.

## Требования к окружению
- Python 3.10+
- ОС: Linux / Windows / macOS

## Установка и запуск
```bash
python3 src/main.py
```

## Структура проекта
- `src/` — исходный код
- `docs/` — документация (ТЗ, описание)
- `tests/` — тесты

## Стратегия ветвления

В проекте используется **Git Flow**:

- `main` — стабильная ветка, в неё попадает только проверенный код.
- `develop` — основная ветка разработки, сюда сливаются фичи.
- `feature-*` — ветки для отдельных задач, после завершения сливаются в `main`/`develop`.

**Обоснование:** Git Flow хорошо подходит для проектов с чёткими релизами
и параллельной работой нескольких разработчиков. Он разделяет стабильный
и разрабатываемый код, что снижает риск попадания багов в релиз.
