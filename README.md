# MatrixNegativeColumns

## Назначение
Программа для поиска номеров столбцов вещественной матрицы n × m,
все элементы которых строго отрицательны (версия A).

## Требования к окружению
- Python 3.10+
- ОС: Linux / Windows / macOS

## Установка и запуск
```bash
python3 src/main.py
```

## Структура проекта
- `src/` — исходный код
- `docs/` — документация (ТЗ, описание)
- `tests/` — тесты
