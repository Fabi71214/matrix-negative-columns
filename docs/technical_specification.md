# Техническое задание (по ГОСТ 19.201-78)

## 1. Введение

### 1.1 Наименование программы
Программа поиска отрицательных столбцов матрицы («MatrixNegativeColumns»).

### 1.2 Краткая характеристика области применения
Программа предназначена для анализа двумерных массивов вещественных чисел
(матриц) размерности n × m и автоматического определения индексов (номеров)
тех столбцов, все элементы которых являются строго отрицательными.
Применяется в учебном процессе, при решении задач линейной алгебры,
а также в качестве вычислительного модуля в системах статического анализа данных.

## 2. Основания для разработки
Разработка выполняется в рамках лабораторной работы №1 по дисциплине
«Инструментальные средства разработки программного обеспечения» согласно
учебному плану специальности ФГБОУ ВО «Липецкий государственный технический
университет» (Кафедра автоматизированных систем управления).
Шифр темы: «Матр-09».

## 3. Назначение разработки

### 3.1 Функциональное назначение
Программа должна:
- запрашивать у пользователя размерность матрицы (n и m);
- проверять корректность ввода размерностей (целые положительные числа);
- организовывать интерактивный ввод вещественных элементов матрицы n × m;
- осуществлять обход структуры данных для анализа знаков элементов;
- определять столбцы, содержащие исключительно отрицательные элементы (< 0);
- выводить упорядоченный список номеров таких столбцов;
- выдавать уведомление, если ни один столбец не удовлетворяет условию.

### 3.2 Эксплуатационное назначение
Программа эксплуатируется на ПК под управлением Windows или Linux
в интерактивном консольном режиме. Не требует специальной подготовки
пользователя.

## 4. Требования к программе

### 4.1 Требования к функциональным характеристикам

#### 4.1.1 Состав выполняемых функций
- Ввод n и m с валидацией (n <= 0, m <= 0, нечисловые символы).
- Позелментный ввод вещественной матрицы с контролем формата.
- Алгоритмический анализ матрицы по столбцам.
- Формирование списка номеров целевых столбцов.
- Вывод результатов в консоль.
- Возможность циклического повторения расчётов.

#### 4.1.2 Организация входных и выходных данных
- Входные данные: вводятся с клавиатуры. Разделитель целой и дробной части — точка.
- Выходные данные: исходная матрица (для контроля) и список номеров столбцов.

#### 4.1.3 Временные характеристики
Время выполнения для матриц до 100×100 — не более 1 секунды.

### 4.2 Требования к надёжности
- Устойчивость к ошибочному вводу (буквы, пустые строки, спецсимволы).
- При ошибке — сообщение и повторный запрос.
- Вероятность безотказной работы при корректных данных — 100%.

### 4.3 Условия эксплуатации

#### 4.3.2 Требования к персоналу
Минимальные навыки работы с ПК на уровне оператора консольных приложений.

#### 4.3.3 Состав и параметры технических средств

- RAM не менее 512 МБ;
- Свободное место не менее 20 МБ;
- ОС Windows 7/10/11 или Linux;
- Python 3.x (или компилятор C++).

### 4.4 Требования к информационной и программной совместимости
Автономный консольный скрипт/приложение. Используются стандартные
конструкции и встроенные типы данных языка.

### 4.5 Требования к транспортировке и хранению
