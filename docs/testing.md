## 2. Баг-репорты

### Баг-репорт №1
- **Заголовок:** `validate_and_prepare_payload()` не проверяет соответствие размеров матрицы параметрам `n` и `m`.
- **Описание:** При передаче `n=3, m=3` и матрицы размером `2x2` функция не выбрасывала исключение, что приводило к `IndexError` на этапе расчёта.
- **Шаги воспроизведения:** Вызвать `validate_and_prepare_payload(3, 2, [[-1.0, -2.0], [-3.0, -4.0]])`.
- **Ожидаемое поведение:** Исключение `ValueError`.
- **Фактическое поведение:** Возврат некорректного DTO без ошибки.
- **Тяжесть:** высокая. **Приоритет:** высокий. **Статус:** исправлено.

### Баг-репорт №2
- **Заголовок:** `find_negative_columns()` возвращает ложные отрицательные столбцы при `n <= 0`.
- **Описание:** При `n=0, m=2` внутренний цикл по строкам не выполнялся, флаг `prov` оставался `True` и возвращался список `[0, 1]`.
- **Шаги воспроизведения:** Вызвать `find_negative_columns(0, 2, [])`.
- **Ожидаемое поведение:** Исключение `ValueError`.
- **Фактическое поведение:** Возврат списка `[0, 1]`.
- **Тяжесть:** высокая. **Приоритет:** высокий. **Статус:** исправлено.
